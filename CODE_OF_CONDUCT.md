# Code de conduite

Ce projet adopte le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : soyez respectueux et bienveillant, acceptez les critiques constructives, et concentrez-vous sur ce qui est le mieux pour la communauté. Le harcèlement, les insultes et les attaques personnelles ne sont pas tolérés.

Pour signaler un comportement inacceptable, utilisez le signalement privé de GitHub ou contactez le mainteneur via son profil. Les signalements sont traités de façon confidentielle.
